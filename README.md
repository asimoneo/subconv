# Subconv (OpenWrt Subscription Converter)

**Subconv** — это плагин с веб-интерфейсом LuCI для OpenWrt. Предназначен для автоматической загрузки, умного парсинга (Base64, JSON, YAML) и конвертации прокси-подписок из https:// ссылок (пока не включая протоколы `vless://`, `happ://` и др.) в чистые локальные списки узлов для клиентов вроде **Re:HomeProxy**.

## 📌 Основные возможности
* **Умный парсинг:** Автоматически распознает Base64, открытый текст, а также готовые JSON/YAML конфиги (Clash/Mihomo). Пока еще не поддерживает кастомные схемы `happ://` Но скоро
* **Защита от утечек:** URL подписок в таблице замаскированы (эффект спойлера с размытием), что исключает утечку приватных ссылок при публикации скриншотов.
* **Адаптация клиента:** Тонкая настройка `User-Agent` (список популярных клиентов + ручной ввод), `HWID`, `OS` и `Модель` устройства. Если вашему провайдеру впн вдруг надо что-то конкретное.
* **Асинхронное обновление:** Фоновое скачивание по расписанию через Cron или пакетно кнопкой «Обновить все».
* **Безопасность:** Проверка на дубликаты имен при создании подписки, автоочистка локальных файлов при удалении и встроенный подробный журнал отладки (с фиксацией HTTP-кодов ответа).

## 🚀 Установка

Выполните в терминале роутера по SSH:

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/asimoneo/subconv/main/install.sh || curl -fsSL https://raw.githubusercontent.com/asimoneo/subconv/main/install.sh)"
```

## ⚙️️ Использование в HomeProxy

1. Откройте **Службы -> Subconv** в LuCI.
2. Заполните параметры подписки (уникальный ID, прямая ссылка, передаваемые данные).
3. Скопируйте локальную ссылку вида `[http://127.0.0.1/ID.txt](http://127.0.0.1/ID.txt)` и вставьте ее в настройки HomeProxy.
4. **Важно:** отключите пункт «Обновлять подписки через прокси» в клиенте HomeProxy, чтобы он не пытался через впн заходить сам на себя.
